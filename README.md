# ☁️ CloudPulse — A Living View of the Cloud

**CloudPulse** is an AWS cloud project that demonstrates static website hosting using Amazon S3 and website request monitoring using Amazon CloudWatch.

## 🌐 Live Website

[**Visit CloudPulse Website**](http://sanket-static-website-2026.s3-website.ap-south-1.amazonaws.com/)

## 🚀 Project Overview

CloudPulse showcases how a static website can be hosted on AWS and how website request activity can be monitored using CloudWatch metrics.

The project focuses on practical AWS cloud concepts, website deployment, and basic monitoring.

## 🏗️ AWS Architecture

- **Amazon S3:** Stores and hosts the static website files.
- **Amazon CloudWatch:** Monitors available website request metrics.
- **AWS Region:** Asia Pacific (Mumbai) — `ap-south-1`
- **GitHub:** Stores the project source code.

## ✨ Features

- Responsive, modern dark-themed website.
- Static website hosting using Amazon S3.
- Website request monitoring with Amazon CloudWatch.
- Public GitHub repository for source code.
- Hands-on experience with AWS deployment concepts.

## ⚙️ Deployment Summary

1. Created an S3 bucket for website hosting.
2. Uploaded `index.html` to the bucket.
3. Configured static website hosting.
4. Opened the live website using the S3 website endpoint.
5. Created a CloudWatch dashboard to review website request metrics.
6. Uploaded the source code to GitHub.

## 📈 Monitoring

The CloudWatch dashboard is named `S3-Website-Monitoring`. It is used to review available S3 request metrics.

**Note:** Website metrics are monitored separately in CloudWatch; they are not displayed as live data on the website itself.
